# Number Bond Garden

A web game of matching pairs of numbers that add up to 10. Strategy and forward-thinking are needed to be able to consistently clear the board. Inspired by Sigmar's Garden, a solitaire game by Zachtronics.

Play here: [https://spheniscine.github.io/number-bond-garden/]<br>
Or here (ad-supported) [[https://www.onlinemathlearning.com/fraction-concoction-game.html](https://www.onlinemathlearning.com/number-bond-garden-game.html)]
